# Chat-loop repair — 2026-10-03

## Confirmed mechanism
The pre-repair validator rejected somatic questions whenever mapping was incomplete, regardless of mode. Body requires somatic clarification before its mapping is complete. Generation and validation therefore contradicted each other. A deterministic reproduction against commit 5e05c14 rejected a shoulder-clarification question with "Somatic gate violated".

The numbered ModeStep keyword check also remained mandatory even when the generator treated that step as advisory. After both generation attempts failed validation, the canned recovery answer bypassed validation. Historical per-call validation logs were not retained, so the precise rejection reason of each historical turn cannot be reconstructed.

## Repair
- Scope the Dream somatic gate to Dream.
- Respect the Body state machine and advisory numbered steps in validation.
- Recognize sleep/constipation and short localization/quality answers.
- Do not infer a figure from the word "as if" alone.
- Separate confusion about the interface from difficulty in daily interactions.
- Preserve Cyrillic й while normalizing Spanish accents.
- Compare repeated questions rather than shared words in reflections; validate recovery answers too.
- Recover using the missing Body dimension; expose Retry when no distinct recovery is available.
- Keep saved user answers on retry; do not advance a step after AI generation failure.
- Treat inactivity as a resumable pause, using the last message rather than start time. Ask for the person's reason.
- Recommend medical assessment for constipation continuing despite attempted self-care, without attributing a physical cause or prescribing treatment.

## Verification
Regression tests exercise the validator, the full generation/retry path with a mocked gateway, and maintenance/follow-up handlers with a mocked data client. No production user records were altered and no user-identifying data are included in the tests.
